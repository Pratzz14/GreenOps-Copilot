# Feasibility

The Gold scorecard evaluates the recorded baseline and eligible measures
against 25% annual CHF savings, 40% annual location-based CO₂ savings, and
CHF 16,500 maximum implementation cost.

The sample run is **unassessed**. The recorded CHF subtotal has missing and
review charges. The energy and direct-CO₂ estimates cover only workloads
with supported quantities and factors. The automatic package selects modeled SaaS reductions with persistent
inactivity, priced Final observations, and a documented notice window.
The conditional package additionally includes proposals with unresolved
operational or pricing assumptions. Each package has its own draft measures
CSV. Neither package establishes challenge target attainment.

Before claiming attainment, resolve baseline coverage and the Swiss direct-CO₂
factor, confirm mixed workload locations where material, and validate the
schedule, prices and contractual rights for selected measures. The scorecard
tests exact unrounded margins and reports which scenarios pass after these
preconditions are met. [Assumptions](ASSUMPTIONS.md)
